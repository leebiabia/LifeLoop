澄清问题 1：实现优先级

PRD 定义了 5 个 Tab 和完整 MVP 范围。你希望按什么顺序推进？

A

核心先行

先完成数据模型 + DoList + Goal 系统（纯逻辑层），再逐一搭建 Tab UI。好处是底层稳固，UI 只是展示层。适合「先把东西做对，再做好看」的思路。

B

页面驱动

按 Tab 顺序逐个完成：Today → Inbox → Goal → 统计 → 我的。每个 Tab 包含其所需的完整数据模型 + ViewModel + View。好处是每个阶段都有可看可交互的东西。

C

骨架优先

先搭建完整的应用骨架（TabView + 所有页面空壳 + 基础数据模型），确保导航结构正确，然后逐模块填肉。好处是架构从第一天就完整，不会后期重构导航结构。

💡 无论选哪个，数据模型设计都会在编码前完成。区别在于开发顺序和反馈节奏。
